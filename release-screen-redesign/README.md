# Редизайн экрана релиза (AnilibriaRefresh)

Пакет для реализации нового экрана деталей релиза в стиле Material 3 Expressive.
Проект — KMP/Compose Multiplatform, общий UI живёт в `commonMain`.

## Что внутри

| Путь | Что это |
|---|---|
| `mockup/release-screen.html` | Интерактивный HTML-макет. Открыть в браузере (лучше в мобильной эмуляции, ширина 360–412). Меню ⋮ → «Состояния макета» переключает демо-состояния. |
| `docs/01-ux-spec.md` | Структура экрана, порядок блоков, поведение и все состояния. Источник истины по UX. |
| `docs/02-data-mapping.md` | Какое поле бэка куда идёт, производные значения, известные странности ответа. |
| `docs/03-compose-implementation.md` | Как это собрать в Compose: архитектура экрана, скролл-координация, компоненты, состояние. |
| `docs/04-acceptance-checklist.md` | Чеклист приёмки. Идти по нему в конце. |
| `reference/before-*.png` | Скриншоты текущего экрана (до редизайна). |
| `reference/release-response.example.json` | Пример ответа `release` с бэка. |

## Порядок работы для агента

1. Прочитать `docs/01-ux-spec.md` целиком, затем открыть макет и пройти все демо-состояния.
2. Изучить существующий код экрана релиза и UI-кит проекта. **Сначала искать готовые компоненты в собственном UI-ките** (в нём уже есть сегментированные list items по гайдлайнам M3 Expressive) и только потом писать новые.
3. Сверить `docs/02-data-mapping.md` с реальными DTO/доменными моделями проекта. Если поля называются иначе — адаптировать, не переименовывать доменные модели ради документа.
4. Реализовать по `docs/03-compose-implementation.md`, придерживаясь существующих паттернов проекта (Orbit MVI, `AsyncField`, Arrow `Either`, Paging 3 с jump scrolling, SQLDelight offline-first).
5. Пройти `docs/04-acceptance-checklist.md`.

## Важные договорённости

- Макет — ориентир по структуре, иерархии и поведению, а не попиксельный эталон. Цвета берутся из темы приложения (dynamic color по постеру, если он уже реализован), отступы и типографика — из UI-кита.
- Текущий релиз **уже вырезается из франшизы на уровне репозитория**. Если после фильтрации список пуст — всё, что связано с франшизой, на экране не показывается (подробности в спеке).
- Данные в макете частично выдуманы (названия серий, команда, время выхода 18:00). В реализации показывать только то, что реально приходит с бэка.
- Иконки в макете — Material Symbols Rounded. В проекте использовать тот набор иконок, который уже подключён.
