# 04. Чеклист приёмки

## Структура и дубли
- [ ] Над вкладками только: hero, мета-чипы, название, подсказки/баннер, play + избранное, статус, карточка следующей серии.
- [ ] Нет отдельной карточки «последней/новой серии».
- [ ] Нет чипа статуса онгоинга на постере; `notification` с бэка не выводится.
- [ ] Иконка избранного — сердце, как в нижней навигации.
- [ ] Нижняя навигация скрыта на экране релиза.

## Шапка
- [ ] Название не обрезается при любой длине.
- [ ] Альтернативные названия раскрываются и копируются.
- [ ] «Продолжить» показывает номер серии и остаток; без прогресса — «Смотреть», «Серия 1».
- [ ] Shape morph на play, избранном, статусе, колокольчике.
- [ ] Карточка следующей серии только у онгоинга; дата считается из `publish_day` корректно.
- [ ] При блокировке: баннер с причиной, play disabled, FAB скрыт, есть выход во внешний плеер.

## Вкладки и скролл
- [ ] Вкладки липнут под top bar; top bar становится непрозрачным, когда название уходит.
- [ ] Свайп и тап переключают вкладки; индикатор по ширине текста.
- [ ] У каждой вкладки свой скролл; свёрнутая шапка не раскрывается при переключении.
- [ ] Драг по шапке скроллит активную вкладку.
- [ ] Вкладка по умолчанию: с прогрессом — «Серии», без — «О релизе»; ручной выбор не сбрасывается при повороте.

## Серии
- [ ] Сегментированные list items из UI-кита (радиусы first/middle/last).
- [ ] Пустое `name` → title «Серия N», без пустого места в карточке.
- [ ] Дробный ordinal через запятую + бейдж «Спешл».
- [ ] Текущая серия выделена, вместо даты — «Остановились на …».
- [ ] Панель инструментов липнет под вкладками.
- [ ] На 3000 серий: плавный скролл, работают «Где остановился», «№ серии», диапазоны; активный диапазон следует за скроллом.
- [ ] Последний элемент не перекрыт FAB.

## О релизе
- [ ] Описание сворачивается/разворачивается с анимацией.
- [ ] Франшиза: текущий релиз отсутствует, номера карточек исходные (с пропуском), есть сводка.
- [ ] Пустая франшиза → нет секции, нет чипа «Часть N из M», нет подсказки.
- [ ] Подсказка «К 1 части» только у нового зрителя и только если релиз не первый.
- [ ] Жанры с картинкой и количеством; команда; подробности (длительность, обновление, трейлер, внешний плеер).

## Оценки
- [ ] Гистограмма анимируется один раз при первом показе вкладки; нет деления на ноль.
- [ ] Плитки Shikimori/MAL открывают ссылки и скрываются при отсутствии данных.
- [ ] «Кто смотрит» + инсайт по доле брошенных.

## Общее
- [ ] Светлая и тёмная тема; цвета только из темы.
- [ ] Загрузка (скелетоны), ошибка с повтором, оффлайн.
- [ ] Гейт для `is_adult`.
- [ ] `contentDescription`, семантика toggle/tab, зоны нажатия ≥ 48dp.
- [ ] Уважается системное уменьшение анимаций.
- [ ] Превью для всех состояний; юнит-тесты маппера проходят.
