# 01. UX-спецификация экрана релиза

## Принцип

Экран отвечает на два вопроса в таком порядке:

1. **«Что это и смотреть ли?»** — шапка (всегда видна до вкладок).
2. **«Где мне продолжить / что узнать подробнее?»** — вкладки.

Ни одна информация не дублируется: если факт уже показан в одном месте, во втором его нет.

## Общая структура (сверху вниз)

```
┌ TopAppBar (оверлей): ← назад · [заголовок при скролле] · поделиться · ⋮
├ Hero: постер на всю ширину, градиент-скрим в цвет поверхности
├ Мета-чипы: [Часть N из M]* [Завершён]* [16+] [ТВ] [Зима 2026] [12 эп. по 24 мин]
├ Название (без обрезки) + англ. название + «ещё N названий» (раскрывается)
├ Подсказка «Это вторая часть»*            ← только новый зритель
├ Баннер блокировки*                         ← только при гео/копирайт-блоке
├ [ ▶ Продолжить / Смотреть  ] [ ♥ 25,5K ]
├ Button group статуса в списке: Смотрю | В планах | Просмотрено | Отложено | Брошено
├ Карточка «Серия 8 выйдет в воскресенье» + колокольчик*   ← только онгоинг
├ Tabs (sticky): Серии [N] | О релизе | Оценки
└ HorizontalPager со страницами вкладок
```
`*` — условные блоки.

### Почему именно эти блоки над вкладками

- Постер, чипы, название — идентификация тайтла.
- «Продолжить» и избранное — главное действие экрана.
- Статус в списке — действие пользователя, а не информация, поэтому не прячется во вкладку.
- Карточка следующей серии — актуальна только для онгоинга; подписка на уведомление удобнее всего именно здесь.
- Баннер блокировки — объясняет, почему кнопка воспроизведения неактивна.

## Шапка — детали

### TopAppBar
- Поверх hero, прозрачный; иконки-кнопки на полупрозрачной подложке с блюром (если блюр недоступен — подложка `surface` с альфой ~0.72).
- Когда название (`h1`) уходит под top bar — фон становится `surface`, появляется название в одну строку с многоточием, у кнопок исчезает подложка.
- ⋮ открывает bottom sheet: «Скопировать ссылку» (по `alias`), «Скопировать название».

### Мета-чипы
- **«Часть N из M»** — кликабельный, tonal primary. Тап: переключить на вкладку «О релизе» и проскроллить к секции «Франшиза». Показывается только если после фильтрации во франшизе есть другие релизы.
- **«Завершён»** — только если `!is_ongoing && !is_in_production`. Для онгоинга чипа нет: это сообщает карточка следующей серии.
- **Возраст** — `age_rating.label`, контрастный (inverse) чип; long-press/tooltip — `age_rating.description`.
- **Тип** — `type.description`.
- **Сезон** — `season` + `year` («Зима 2026»). Иконка по сезону.
- **Серии** — «`episodes_total` эп. по `average_duration_of_episode` мин».

### Название
- `name.main` целиком, без `maxLines`/ellipsis. Крупный узкий шрифт (variable-width, если в UI-ките есть; иначе обычный headline с `TextAutoSize`/уменьшением кегля для очень длинных названий).
- Ниже `name.english` (1–2 строки).
- `name.alternative` разбивается по запятой; кнопка «ещё N названий» раскрывает их чипами, тап по чипу копирует текст (snackbar «Скопировано»).

### Подсказка о предыдущей части
- Условие: у пользователя нет прогресса по релизу, нет статуса в списке, и текущий релиз не первый во франшизе.
- Текст: «Это вторая часть. Сюжет продолжает первый сезон.» + кнопка «К 1 части» (открывает первый релиз франшизы).
- Пользователю, который уже смотрит, не показывается.

### Баннер блокировки
- Условие: `is_blocked_by_geo || is_blocked_by_copyrights`. Тексты различаются по причине.
- Цвет error-container, кнопка «Открыть внешний плеер» (`external_player`).
- Основная кнопка воспроизведения при этом disabled, FAB не показывается.

### Главные действия
- **Play-кнопка** (крупная, pill, высота ~68dp):
  - есть прогресс → «Продолжить», подпись «Серия 7, осталось 12 мин», фон кнопки частично залит прогрессом серии;
  - нет прогресса → «Смотреть», подпись «Серия 1, 24 мин».
  - Иконка play в форме-«печеньке» (MaterialShapes Cookie).
  - При нажатии — shape morph (радиус уменьшается), пружинная анимация.
- **Избранное** — квадрат с большим радиусом; в выбранном состоянии становится кругом и заливается primary. Под иконкой счётчик `added_in_users_favorites` в компактной форме (25,5K). Иконка — сердце (консистентно с нижней навигацией, звезду не использовать).

### Статус в списке
- Connected button group, 5 вариантов, single-select, можно снять выбор. Горизонтально скроллится, если не влезает.
- Выбранный сегмент морфится в полный pill.
- Смена статуса → snackbar «Перенесено в „В планах“».

### Карточка следующей серии
- Только если `is_ongoing`.
- Слева «календарик» в форме Cookie: число и месяц ближайшей даты выхода (по `publish_day`).
- Текст: «Серия {последняя + 1} выйдет в {день недели}», подпись — относительное время («через 5 дн. 12 ч»). Время суток показывать только если бэк его отдаёт (в макете 18:00 — заглушка).
- Колокольчик — toggle уведомления о выходе серии; включённый морфится в скруглённый квадрат и заливается.
- Строку `notification` с бэка («Серии выходят по воскресеньям») отдельно **не выводить** — дублирует карточку.

## Вкладки

- Sticky под top bar. Primary tabs, индикатор по ширине контента, переезд с пружиной.
- Свайп между вкладками (pager).
- У каждой вкладки **свой** скролл. При переключении, если вкладки уже прилипли, шапка остаётся свёрнутой и восстанавливается сохранённая позиция вкладки (или её начало).
- **Вкладка по умолчанию**: есть прогресс по релизу → «Серии»; нет → «О релизе». Выбирается один раз при первой загрузке, дальше — выбор пользователя (переживает поворот экрана / process death).

### Вкладка «Серии»

Список может содержать **тысячи** элементов, поэтому это отдельная вкладка, где кроме списка ничего нет.

**Панель инструментов** (sticky под вкладками):
- «Где остановился» — прыжок к текущей серии с подсветкой (скрыт, если прогресса нет).
- Сортировка: «Сначала старые» / «Сначала новые». По умолчанию — по порядку (старые сверху).
- Поле «№ серии» + кнопка → прыжок к серии по номеру (показывается, если серий > 100).
- Чипы диапазонов «1–100», «101–200»… (если серий > 100). В Compose это **якоря для jump-scroll**, а не отдельные страницы: тап прокручивает к первому элементу диапазона, выбранный чип следует за текущей позицией скролла.

**Элемент списка** — сегментированный list item из UI-кита:
- Контейнеры с зазором 2dp; у первого большой верхний радиус, у последнего — нижний, у средних маленький.
- Слева превью серии во всю высоту элемента (~128×84dp), справа внизу на превью — длительность. Внизу превью тонкая полоска прогресса, если серия начата и не досмотрена.
- Текст:
  - если `name` не пустое: надпись «Серия N» (label) + `name` (title, до 2 строк);
  - если `name` пустое (частый случай): `«Серия N»` становится title, надпись не выводится.
- Нижняя строка — дата и время выхода серии («20 июля 2026, 21:06»). Для текущей серии вместо даты — «Остановились на 11:27».
- Дробный `ordinal` (6.5, 12.5) выводится через запятую и получает бейдж «Спешл».
- Трейлинг: `check_circle` (залитая, primary) — просмотрено; `play_circle` — нет.
- Текущая серия: фон `secondaryContainer`.
- Нажатие — shape morph к единому радиусу.

### Вкладка «О релизе»

Порядок:
1. **О сюжете** — `description`, свёрнуто до ~4 строк с градиентным затуханием, кнопка «Читать полностью / Свернуть».
2. **Франшиза** — см. ниже.
3. **Жанры** — чипы с мини-картинкой жанра (`genres[].image`) и числом `total_releases`. Тап — каталог по жанру.
4. **Работа над релизом** — горизонтальный ряд: аватар (если нет — инициал в форме Cookie разных вариантов), имя, роль.
5. **Подробности** — сегментированный список:
   - Общая длительность (`episodes_total × average_duration_of_episode`).
   - Последнее обновление (`fresh_at`, относительное время).
   - Трейлер (YouTube) — если есть id.
   - Внешний плеер (`external_player`) — «Если плеер не работает».

#### Франшиза
- **Текущий релиз уже вырезан репозиторием.** Если оставшийся список пуст — секция, чип «Часть N из M» и подсказка о предыдущей части не показываются.
- Заголовок «Франшиза» + «Все» (полный список франшизы отдельным экраном/шитом).
- Подзаголовок-сводка по всей франшизе: «4 релиза с 2025 по 2027, всего 27 серий, около 10 часов».
- Горизонтальная **M3 Carousel** (multi-browse), карточки ~172×244dp с маскированием краёв.
- Карточка: постер, порядковый номер **в исходной франшизе** (то есть 1, 3, 4 — номер текущего пропущен), название (до 2 строк), «Тип, год, N серий», статус: «Просмотрено» (из коллекций пользователя) или «Анонс» (`is_in_production`).
- Тап — переход на релиз.

### Вкладка «Оценки»

1. Карточка рейтинга: крупная оценка `rating.average` в форме Cookie + число голосов; справа гистограмма `rating.distribution` (10 → 1), бары нормированы по максимуму, анимируются при первом показе вкладки.
2. Ниже две плитки: Shikimori и MyAnimeList — оценка + число голосов, тап открывает `url`.
3. **Кто смотрит** — stacked bar по пяти коллекциям + легенда с числами + инсайт (доля брошенных: `abandoned / сумма всех`, например «Бросили всего 0,3%»). Инсайт показывать только если доля < 5%, иначе нейтральный текст или ничего.

## Плавающие элементы

- **FAB продолжения** — extended FAB «▶ Серия 7» (или «Смотреть»), появляется с пружиной, когда основная play-кнопка уходит за верхнюю границу экрана. Скрыт при блокировке.
- Нижняя навигация приложения на этом экране **скрыта** (экран деталей).
- Снизу у контента страниц — отступ под FAB, чтобы он не перекрывал последний элемент.

## Состояния (все есть в макете, меню ⋮)

| Состояние | Что меняется |
|---|---|
| Онгоинг (по умолчанию) | Карточка следующей серии, чипа «Завершён» нет |
| Завершён | Чип «Завершён», карточки следующей серии нет |
| Гео-блок | Баннер, play disabled, FAB скрыт |
| 3000 серий | Поле «№ серии», чипы диапазонов, пустые названия → «Серия N» |
| Новый зритель | «Смотреть», нет прогресса, нет статуса, подсказка о предыдущей части, вкладка по умолчанию «О релизе», «Где остановился» скрыт |
| Без франшизы | Нет чипа «Часть N из M», секции «Франшиза», подсказки |

Дополнительно реализовать (в макете нет): загрузка (скелетоны в шапке и списке), ошибка загрузки с повтором, оффлайн (данные из SQLDelight + индикатор), взрослый контент (`age_rating.is_adult`) — гейт подтверждения возраста перед показом постера.

## Доступность

- Все иконки-кнопки с `contentDescription`.
- Toggle-кнопки (избранное, колокольчик, сегменты статуса) — семантика `toggleable`/`selected`.
- Tabs — `Role.Tab`, pager-страницы доступны свайпом и тапом.
- Минимальная зона нажатия 48dp.
- Анимации уважают системную настройку уменьшения движения.
